# Hi there 👋

Vantern is an organization that mostly focuses on open-source projects, letting others view and contribute to them freely.

## Contributing

Contributing to Vantern's projects can be done by forking the repository you are contributing to and creating a pull request!

Most repositories contain a `CONTRIBUTING.md` file, which gives you more detail on how to contribute to that specific repository.

## Links

Vantern has a few important links for you!

Our [Discord](https://vantern.org/discord), our [Status Page](https://status.vantern.org/), and of course our [Documentation](https://docs.vantern.org) for the repositories that need it.
